# Тест-кейсы спринта 2

Запуск: `php artisan migrate:fresh --seed`, затем `php artisan test`.

| Сценарий | Действие | Ожидаемый результат |
|---|---|---|
| Каталог | GET /movies | 12 карточек на первой странице, всего 30 |
| Пагинация | GET /movies?page=2 | Следующие 12 карточек |
| Поиск | `?search=ИНТЕР` | «Интерстеллар», без учёта регистра |
| Пустой поиск | `?search=неттакогофильма` | Сообщение «Ничего не найдено» |
| Жанр и год | `?genre=fantastika&year=2014` | Только подходящие фильмы |
| Сортировка | `?sort=title`, `?sort=year`, `?sort=rating` | Соответствующий порядок |
| Сохранение фильтров | Перейти на вторую страницу отфильтрованного каталога | Параметры запроса остаются в URL |
| Карточка | GET /movies/interstellar | Год, страна, режиссёр, длительность, жанры |
| Страница | GET /page/about | Страница из БД |
| Неизвестный URL | GET /page/missing и /movies/missing | 404 |
